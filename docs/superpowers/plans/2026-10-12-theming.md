# Theming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Built-in themes (Default, Tron Legacy, Matrix, Synthwave, Amber CRT) that restyle every Tinycast-drawn surface with their own colors, fonts, surfaces, glow and animated backdrop, with Default unchanged.

**Architecture:** Plain theme values live in `Features/Theming/Model/` (no AppKit or SwiftUI). A global `@Observable` `ThemeStore.active` holds the resolved `ThemePalette`; `Theme.Colors` and `Theme.Typography` become computed properties that read it, so Observation repaints every view on a switch without call-site changes. Surfaces go through one `themedSurface`/`themedPanel` modifier pair, and backdrops are stateless `TimelineView` + `Canvas` views.

**Tech Stack:** Swift 6.4 (language mode 6, complete strict concurrency), SwiftUI + AppKit, macOS 26 SDK 27, XcodeGen, standalone `swiftc` test harnesses run by `./Scripts/run-tests.sh`, SwiftLint.

**Spec:** `docs/superpowers/specs/2026-10-12-theming-design.md`

## Global Constraints

- macOS 26 minimum, Swift 6 language mode, data-race violations are errors; no third-party dependencies.
- Default theme renders identically to today; every Default Dark color is the shipped literal (pinned by `Tests/appearance-test.swift`).
- A file under `Features/*/Model/` imports neither AppKit nor SwiftUI.
- Never edit `DesignSystem/Scrolling/EdgeDissolve.swift` or `ThinScrollbar.swift`.
- Extensions stay inside `Features/Extensions/`: they read `Theme` base tokens and `Theme.Surfaces` data, never a DesignSystem view for their look.
- Native titled windows stay unthemed: Settings, About, Updates, Support, Onboarding, command output. Files under any `Settings/` folder, `Features/Onboarding/`, `Features/Support/`, `Features/Updates/`, `Windows/About/`, and `CommandOutputView`/`TerminalLogView` are out of scope.
- Comments: rare, one line, explain why, max 100 characters, never two in a row, never comment the change you just made.
- New preference gets a `SettingsFileKey` binding; `appearance.theme` keeps meaning System/Light/Dark; the new key is `appearance.visualTheme`, UserDefaults key `visualTheme`.
- After editing `project.yml`, run `xcodegen generate` and commit both files.
- Definition of done for every task: `./Scripts/run-tests.sh` passes; Debug build has no new warnings; `./Scripts/lint.sh` clean; `grep -rln 'import AppKit\|import SwiftUI\|import Cocoa' Tinycast/Features/*/Model/` prints nothing; docs the change made wrong are fixed in the same commit.
- Commits and PR bodies carry no `Co-Authored-By` or other attribution lines.
- Backdrop budget: zero CPU while hidden (hard rule); roughly 5-8% of one core while visible (target, Devon 2026-10-12); under 8 MB extra resident memory.

## Review Focus

1. A theme switch while the palette, a note, a menu or the chat window is open: every surface repaints, including AppKit text that copied a color or font (note editor, chat link color). Pinned by the `generation` checks in Task 4 and the reapply code in Task 12.
2. An unknown stored theme value (a build with more themes wrote it, or a hand-edited settings.json or backup): reads as Default, never crashes. Pinned in Task 5.
3. Interface Size other than Standard combined with a bundled font: text scales, and the search field's measured width matches the rendered font. Pinned in Task 10.
4. Light appearance (or System flipping) while a non-Default theme is active: tokens resolve to the light variant. Pinned in Task 13's appearance-test additions.
5. Palette hidden after showing an animated backdrop: CPU returns to idle. Measured in Task 15.

```swift
import Foundation

/// Pins the theme catalog: every theme is complete, Default is today's look, and text stays legible.
@main
struct ThemeTests {
    nonisolated(unsafe) static var failures = 0
    nonisolated(unsafe) static var passes = 0

    static func check(_ label: String, _ ok: Bool, _ detail: String = "") {
        if ok {
            passes += 1
        } else {
            failures += 1
            print("FAIL  \(label)\(detail.isEmpty ? "" : ": \(detail)")")
        }
    }

    static func main() {
        print("# color maths")
        check("hex parses", RGBA(hex: 0xFF8000) == RGBA(1, 128.0 / 255, 0))
        check("black on white is 21:1", abs(ContrastPolicy.ratio(.gray(0), .gray(1)) - 21) < 0.01)
        check("a color on itself is 1:1", abs(ContrastPolicy.ratio(.gray(0.5), .gray(0.5)) - 1) < 0.001)

        print("# every theme is stated")
        for id in ThemeID.allCases {
            check("\(id) definition carries its id", ThemeCatalog.definition(for: id).id == id)
        }

        print("# Default is today's look")
        let standard = ThemeCatalog.standard
        check("ink is white over black", standard.ink == RGBAPair(dark: .gray(1), light: .gray(0)))
        check("surface is black under white", standard.surface == RGBAPair(dark: .gray(0), light: .gray(1)))
        check("no overrides", standard.overrides.isEmpty)
        check("every surface is glass", SurfaceRole.allCases.allSatisfy { standard.surfaces.style(for: $0) == .glass })
        check("no backdrop", standard.backdrop.kind == .none)
        check("no glow", standard.glow == .none)
        check("system faces", standard.faces == .system)

        print("# custom themes are opaque and legible")
        for id in ThemeID.allCases where id != .standard {
            let theme = ThemeCatalog.definition(for: id)
            if case .solid = theme.surfaces.panel {} else { check("\(id) panel is solid", false) }
            for dark in [true, false] {
                let mode = dark ? "dark" : "light"
                let primary = ContrastPolicy.minimumTextContrast(
                    theme, dark: dark, inkAlpha: theme.inkAlpha(.textPrimary, dark: dark))
                let secondary = ContrastPolicy.minimumTextContrast(
                    theme, dark: dark, inkAlpha: theme.inkAlpha(.textSecondary, dark: dark))
                check("\(id) \(mode) primary text ≥ 4.5", primary >= 4.5, String(format: "%.2f", primary))
                check("\(id) \(mode) secondary text ≥ 3", secondary >= 3, String(format: "%.2f", secondary))
            }
        }

        print("\n\(passes) passed, \(failures) failed")
        exit(failures == 0 ? 0 : 1)
    }
}
```

```swift
import Foundation

/// An sRGB color as plain numbers, so a theme can be stated and checked without AppKit.
struct RGBA: Equatable, Sendable {
    let red: Double
    let green: Double
    let blue: Double
    let alpha: Double

    init(_ red: Double, _ green: Double, _ blue: Double, alpha: Double = 1) {
        self.red = red
        self.green = green
        self.blue = blue
        self.alpha = alpha
    }

    /// `0xRRGGBB`, the form every theme states its colors in.
    init(hex: UInt32, alpha: Double = 1) {
        self.init(
            Double((hex >> 16) & 0xFF) / 255, Double((hex >> 8) & 0xFF) / 255,
            Double(hex & 0xFF) / 255, alpha: alpha)
    }

    static func gray(_ level: Double, alpha: Double = 1) -> RGBA {
        RGBA(level, level, level, alpha: alpha)
    }

    func with(alpha: Double) -> RGBA { RGBA(red, green, blue, alpha: alpha) }
}

/// One value per appearance: dark is the design, light its inversion.
struct RGBAPair: Equatable, Sendable {
    let dark: RGBA
    let light: RGBA

    static func both(_ value: RGBA) -> RGBAPair { RGBAPair(dark: value, light: value) }

    func value(dark isDark: Bool) -> RGBA { isDark ? dark : light }
}
```

```swift
import Foundation

/// WCAG contrast over the worst pixel text can sit on: surface, backdrop at full intensity, scrim.
enum ContrastPolicy {
    static func ratio(_ first: RGBA, _ second: RGBA) -> Double {
        let (a, b) = (luminance(first), luminance(second))
        return (max(a, b) + 0.05) / (min(a, b) + 0.05)
    }

    static func minimumTextContrast(_ theme: ThemeDefinition, dark: Bool, inkAlpha: Double) -> Double {
        backgrounds(theme, dark: dark)
            .map { ratio(over(theme.ink.value(dark: dark).with(alpha: inkAlpha), $0), $0) }
            .min() ?? 1
    }

    /// Each surface stop, alone and under each backdrop color, then under the panel scrim.
    private static func backgrounds(_ theme: ThemeDefinition, dark: Bool) -> [RGBA] {
        let bases: [RGBA]
        switch theme.surfaces.panel {
        case .solid(.color(let fill), _, _): bases = [fill.value(dark: dark)]
        case .solid(.verticalGradient(let top, let bottom), _, _):
            bases = [top.value(dark: dark), bottom.value(dark: dark)]
        case .glass, .tintedGlass: bases = [theme.surface.value(dark: dark)]
        }
        let intensity = theme.backdrop.intensity.value(dark: dark)
        let marks = theme.backdrop.kind == .none ? [] : theme.backdrop.colors.map { $0.value(dark: dark) }
        let scrimAlpha: Double
        if case .surface(let darkAlpha, let lightAlpha) = theme.recipe(for: .panelScrim) {
            scrimAlpha = dark ? darkAlpha : lightAlpha
        } else {
            scrimAlpha = 0
        }
        let scrim = theme.surface.value(dark: dark).with(alpha: scrimAlpha)
        return bases.flatMap { base in
            [base] + marks.map { over($0.with(alpha: $0.alpha * intensity), base) }
        }
        .map { over(scrim, $0) }
    }

    /// Source-over onto an opaque color.
    static func over(_ top: RGBA, _ bottom: RGBA) -> RGBA {
        let a = top.alpha
        return RGBA(
            top.red * a + bottom.red * (1 - a), top.green * a + bottom.green * (1 - a),
            top.blue * a + bottom.blue * (1 - a))
    }

    private static func luminance(_ color: RGBA) -> Double {
        func linear(_ c: Double) -> Double { c <= 0.04045 ? c / 12.92 : pow((c + 0.055) / 1.055, 2.4) }
        return 0.2126 * linear(color.red) + 0.7152 * linear(color.green) + 0.0722 * linear(color.blue)
    }
}
```

```swift
import AppKit
import SwiftUI

/// One theme resolved to SwiftUI colors, once per switch rather than per render.
struct ThemePalette {
    let definition: ThemeDefinition
    private let colors: [ColorToken: Color]

    init(_ definition: ThemeDefinition) {
        self.definition = definition
        colors = Dictionary(
            uniqueKeysWithValues: ColorToken.allCases.map {
                ($0, Self.resolve(definition.recipe(for: $0), token: $0, in: definition))
            })
    }

    func color(_ token: ColorToken) -> Color { colors[token]! }

    static func color(_ pair: RGBAPair) -> Color {
        Theme.Colors.adaptive(dark: nsColor(pair.dark), light: nsColor(pair.light))
    }

    private static func resolve(_ recipe: ColorRecipe, token: ColorToken, in theme: ThemeDefinition) -> Color {
        switch recipe {
        case .ink(let dark, let light):
            return tinted(theme.ink, dark: dark, light: light)
        case .surface(let dark, let light):
            return tinted(theme.surface, dark: dark, light: light)
        case .fixed(let pair):
            return pair.dark == pair.light ? Color(nsColor: nsColor(pair.dark)) : color(pair)
        case .role(let role, let dark, let light):
            switch theme.roles.color(for: role) {
            case .system(let system): return withAlpha(systemColor(system), dark: dark, light: light)
            case .rgba(let pair): return tinted(pair, dark: dark, light: light)
            }
        case .system(let system, let dark, let light):
            return withAlpha(systemColor(system), dark: dark, light: light)
        }
    }

    private static func tinted(_ pair: RGBAPair, dark: Double, light: Double) -> Color {
        Theme.Colors.adaptive(
            dark: nsColor(pair.dark.with(alpha: pair.dark.alpha * dark)),
            light: nsColor(pair.light.with(alpha: pair.light.alpha * light)))
    }

    /// Full alpha returns the system color itself, so Default's roles stay the exact same values.
    private static func withAlpha(_ color: Color, dark: Double, light: Double) -> Color {
        if dark == 1, light == 1 { return color }
        if dark == light { return color.opacity(dark) }
        let ns = NSColor(color)
        return Theme.Colors.adaptive(
            dark: ns.withAlphaComponent(dark), light: ns.withAlphaComponent(light))
    }

    private static func systemColor(_ system: SystemColor) -> Color {
        switch system {
        case .accent: .accentColor
        case .blue: .blue
        case .red: .red
        case .green: .green
        case .orange: .orange
        case .yellow: Color(nsColor: .systemYellow)
        case .link: Color(nsColor: .linkColor)
        case .windowBackground: Color(nsColor: .windowBackgroundColor)
        case .white: .white
        }
    }

    static func nsColor(_ value: RGBA) -> NSColor {
        NSColor(srgbRed: value.red, green: value.green, blue: value.blue, alpha: value.alpha)
    }
}
```

```swift
import Observation

/// The active theme; `Theme`'s tokens read it, so a switch repaints every view that used one.
@MainActor
@Observable
final class ThemeStore {
    /// Global like `IconCache.style`: a missed injection in a menu or list would be silent staleness.
    static var active = ThemeStore()

    private(set) var palette = ThemePalette(ThemeCatalog.standard)
    /// For AppKit views that copied a color or font: a new value means reapply.
    private(set) var generation = 0

    var id: ThemeID { palette.definition.id }

    @discardableResult
    func apply(_ id: ThemeID) -> Bool {
        guard id != self.id else { return false }
        palette = ThemePalette(ThemeCatalog.definition(for: id))
        generation &+= 1
        return true
    }
}
```

```swift
struct SolidSurface<S: Shape>: View {
    let fill: SurfaceFill
    let stroke: RGBAPair?
    let glows: Bool
    let shape: S
    @Environment(\.colorScheme) private var colorScheme
    @Environment(\.colorSchemeContrast) private var contrast

    var body: some View {
        let radius = glows && contrast == .standard ? Theme.Effects.glowRadius(dark: colorScheme == .dark) : 0
        shape
            .fill(fillStyle)
            .overlay {
                if let stroke {
                    shape
                        .stroke(ThemePalette.color(stroke), lineWidth: 1)
                        .shadow(color: radius > 0 ? Theme.Effects.glowColor : .clear, radius: radius)
                }
            }
    }

    private var fillStyle: AnyShapeStyle {
        switch fill {
        case .color(let pair):
            AnyShapeStyle(ThemePalette.color(pair))
        case .verticalGradient(let top, let bottom):
            AnyShapeStyle(
                LinearGradient(
                    colors: [ThemePalette.color(top), ThemePalette.color(bottom)],
                    startPoint: .top, endPoint: .bottom))
        }
    }
}
```

```swift
/// Reports whether this view's window is on screen, so animation can stop when it is not.
struct WindowOcclusionReader: NSViewRepresentable {
    let onChange: (Bool) -> Void

    func makeNSView(context: Context) -> ReaderView {
        let view = ReaderView()
        view.onChange = onChange
        return view
    }

    func updateNSView(_ nsView: ReaderView, context: Context) {
        nsView.onChange = onChange
    }

    final class ReaderView: NSView {
        var onChange: (Bool) -> Void = { _ in }
        private var token: NSObjectProtocol?

        override func viewDidMoveToWindow() {
            super.viewDidMoveToWindow()
            token.map(NotificationCenter.default.removeObserver)
            token = nil
            guard let window else { return onChange(false) }
            token = NotificationCenter.default.addObserver(
                forName: NSWindow.didChangeOcclusionStateNotification, object: window, queue: .main
            ) { [weak self] _ in
                MainActor.assumeIsolated { self?.report() }
            }
            report()
        }

        private func report() { onChange(window?.occlusionState.contains(.visible) ?? false) }
    }
}
```

```swift
/// The theme's moving layer: stateless per frame, and paused whenever nobody can see it.
struct PanelBackdrop: View {
    let backdrop: Backdrop
    @Environment(\.accessibilityReduceMotion) private var reduceMotion
    @Environment(\.colorScheme) private var colorScheme
    @State private var isVisible = false

    var body: some View {
        let dark = colorScheme == .dark
        let still = reduceMotion || (!dark && backdrop.lightIsStatic)
        if backdrop.kind != .none {
            TimelineView(.animation(minimumInterval: 1.0 / 30, paused: still || !isVisible)) { timeline in
                Canvas(rendersAsynchronously: true) { context, size in
                    // Wrapped to an hour: a reference-date Double loses sub-frame precision.
                    let time = still ? 0 : timeline.date.timeIntervalSinceReferenceDate
                        .truncatingRemainder(dividingBy: 3600) * backdrop.speed
                    BackdropRenderer.draw(backdrop, in: &context, size: size, time: time, dark: dark)
                } symbols: {
                    BackdropRenderer.symbols(for: backdrop, dark: dark)
                }
            }
            .opacity(backdrop.intensity.value(dark: dark))
            .background(WindowOcclusionReader { isVisible = $0 })
            .allowsHitTesting(false)
            .accessibilityHidden(true)
        }
    }
}

    static func draw(
        _ backdrop: Backdrop, in context: inout GraphicsContext, size: CGSize, time: Double, dark: Bool
    ) {
        switch backdrop.kind {
        case .none, .grid, .codeRain, .sunsetGrid, .scanlines: break
        }
    }

    @ViewBuilder
    static func symbols(for backdrop: Backdrop, dark: Bool) -> some View {
        EmptyView()

    /// A fixed integer hash, so every column and trace is a pure function of its index.
    static func mix(_ value: Int) -> Int {
        var x = UInt64(bitPattern: Int64(value)) &+ 0x9E37_79B9_7F4A_7C15
        x = (x ^ (x >> 30)) &* 0xBF58_476D_1CE4_E5B9

        return Int(truncatingIfNeeded: (x ^ (x >> 31)) & 0x7FFF_FFFF)
```

```swift
import AppKit
import SwiftUI

/// A token's font in the active theme's face; a face equal to Default's returns `base` untouched.
@MainActor
enum ThemeFonts {
    static func font(
        _ role: FontRole, base: Font, style: NSFont.TextStyle, weight: Font.Weight? = nil,
        scale: CGFloat = 1
    ) -> Font {
        let face = ThemeStore.active.palette.definition.faces.face(for: role)
        guard face != ThemeFaces.system.face(for: role) else { return base }
        let size = (NSFont.preferredFont(forTextStyle: style).pointSize * scale).rounded()
        let font: Font
        switch face {
        case .bundled(let bundled):
            guard NSFont(name: bundled.family, size: size) != nil
                || NSFontManager.shared.availableMembers(ofFontFamily: bundled.family) != nil
            else { return base }
            font = .custom(bundled.family, size: size, relativeTo: textStyle(style))
        case .system(let design):
            font = .system(size: size, design: fontDesign(design))
        }
        return weight.map(font.weight) ?? font
    }

    static func nsFont(_ role: FontRole, base: NSFont) -> NSFont {
        let face = ThemeStore.active.palette.definition.faces.face(for: role)
        guard face != ThemeFaces.system.face(for: role) else { return base }
        switch face {
```

```swift
import SwiftUI

/// A perspective floor whose lines stream toward the viewer, with a few light traces riding them.
enum GridBackdrop {
    private static let rows = 14
    private static let columns = 12
    private static let traces = 3

    static func draw(
        _ backdrop: Backdrop, in context: inout GraphicsContext, size: CGSize, time: Double, dark: Bool,
        sunset: Bool
    ) {
        let horizon = size.height * (sunset ? 0.52 : 0.38)
        let floor = size.height - horizon
        let vanishing = CGPoint(x: size.width / 2, y: horizon)
        let line = ThemePalette.color(backdrop.primary)
        let accent = ThemePalette.color(backdrop.secondary)

        var horizontals = Path()
        let phase = (time * 0.35).truncatingRemainder(dividingBy: 1)
        for row in 0..<rows {
            let depth = (Double(row) + phase) / Double(rows)
            let y = horizon + floor * pow(depth, 2.2)
            horizontals.move(to: CGPoint(x: 0, y: y))
            horizontals.addLine(to: CGPoint(x: size.width, y: y))
        }
        context.stroke(horizontals, with: .color(line.opacity(0.35)), lineWidth: 1)

        var verticals = Path()
        let spread = size.width / Double(columns) * 1.6
        for column in -columns...columns {
            verticals.move(to: vanishing)
            verticals.addLine(to: CGPoint(x: vanishing.x + Double(column) * spread, y: size.height))
        }
        context.stroke(verticals, with: .color((sunset ? accent : line).opacity(0.28)), lineWidth: 1)

        guard !sunset else { return }
        for trace in 0..<traces {
            let column = BackdropRenderer.mix(trace * 31) % (columns * 2 + 1) - columns
            let end = CGPoint(x: vanishing.x + Double(column) * spread, y: size.height)
            let progress = (time * (0.18 + 0.07 * BackdropRenderer.unit(trace)) + BackdropRenderer.unit(trace * 7))
                .truncatingRemainder(dividingBy: 1)
            let head = point(from: vanishing, to: end, at: pow(progress, 1.6))
            let tail = point(from: vanishing, to: end, at: pow(max(progress - 0.08, 0), 1.6))
            var path = Path()
            path.move(to: tail)
            path.addLine(to: head)
            let color = trace == 0 ? accent : line
            context.stroke(path, with: .color(color.opacity(0.35)), lineWidth: 6)
            context.stroke(path, with: .color(color), lineWidth: 2)
        }
    }

    private static func point(from start: CGPoint, to end: CGPoint, at t: Double) -> CGPoint {
        CGPoint(x: start.x + (end.x - start.x) * t, y: start.y + (end.y - start.y) * t)
    }
}
```

```swift
import SwiftUI

/// Falling columns of half-width katakana and digits; each column's pace and offset is a hash.
enum CodeRainBackdrop {
    static let glyphs = Array("ｱｲｳｴｵｶｷｸｹｺｻｼｽｾｿﾀﾁﾂﾃﾄﾅﾆﾇﾈﾉﾊﾋﾌﾍﾎﾏﾐﾑﾒﾓﾔﾕﾖﾗﾘﾙﾚﾛﾜﾝ0123456789").map(String.init)
    private static let pitch: CGFloat = 14
    /// Two tags per glyph: the bright head and the body.
    private static let headTagOffset = 1000

    static func draw(_ backdrop: Backdrop, in context: inout GraphicsContext, size: CGSize, time: Double) {
        let columns = Int(size.width / pitch)
        for column in 0..<columns {
            let speed = 40 + Double(BackdropRenderer.mix(column) % 60)
            let length = 8 + BackdropRenderer.mix(column * 7) % 16
            let span = size.height + CGFloat(length) * pitch
            let head = (time * speed + BackdropRenderer.unit(column * 13) * span)
                .truncatingRemainder(dividingBy: span)
            for step in 0..<length {
                let y = head - CGFloat(step) * pitch
                guard y > -pitch, y < size.height + pitch else { continue }
                let flicker = BackdropRenderer.mix(column &* 7919 &+ step &+ Int(time * 6))
                let tag = flicker % glyphs.count + (step == 0 ? headTagOffset : 0)
                guard let symbol = context.resolveSymbol(id: tag) else { continue }
                context.opacity = step == 0 ? 1 : 1 - Double(step) / Double(length)
                context.draw(symbol, at: CGPoint(x: CGFloat(column) * pitch + pitch / 2, y: y))
            }
        }
        context.opacity = 1
    }

    @ViewBuilder
    static func symbols(for backdrop: Backdrop, dark: Bool) -> some View {
        let body = ThemePalette.color(backdrop.primary)
        let head = ThemePalette.color(backdrop.secondary)
        ForEach(glyphs.indices, id: \.self) { index in
            Text(glyphs[index]).font(.system(size: 13, design: .monospaced)).foregroundStyle(body).tag(index)
        }
        ForEach(glyphs.indices, id: \.self) { index in
            Text(glyphs[index]).font(.system(size: 13, weight: .bold, design: .monospaced)).foregroundStyle(head)
                .tag(index + headTagOffset)
        }
    }
}
```

```swift
import SwiftUI

/// Dark: phosphor glow, scanlines and a rare flicker. Light: still paper grain.
enum ScanlineBackdrop {
    private static let grain = 400

    static func draw(_ backdrop: Backdrop, in context: inout GraphicsContext, size: CGSize, time: Double, dark: Bool) {
        guard dark else { return drawPaper(backdrop, in: &context, size: size) }
        let breath = 0.06 + 0.02 * sin(time * 0.5)
        let flicker = BackdropRenderer.mix(Int(time * 10)) % 97 == 0 ? 0.04 : 0
        context.fill(
            Path(CGRect(origin: .zero, size: size)),
            with: .radialGradient(
                Gradient(colors: [ThemePalette.color(backdrop.primary).opacity(breath + flicker), .clear]),
                center: CGPoint(x: size.width / 2, y: size.height / 2), startRadius: 0,
                endRadius: max(size.width, size.height) * 0.7))
        var lines = Path()
        var y: CGFloat = 0
        while y < size.height {
            lines.addRect(CGRect(x: 0, y: y, width: size.width, height: 1))
            y += 3
        }
        context.fill(lines, with: .color(ThemePalette.color(backdrop.secondary).opacity(0.25)))
    }

    private static func drawPaper(_ backdrop: Backdrop, in context: inout GraphicsContext, size: CGSize) {
        var dots = Path()
        for index in 0..<grain {
            let x = BackdropRenderer.unit(index * 2) * size.width
            let y = BackdropRenderer.unit(index * 2 + 1) * size.height
            dots.addRect(CGRect(x: x, y: y, width: 1, height: 1))
        }
        context.fill(dots, with: .color(ThemePalette.color(backdrop.secondary).opacity(0.12)))
    }
}
```
